# 대바늘 도안 기호 체계 (Knit Symbol System)

> 이 문서는 **대바늘(knitting)** 서술형 도안 입력 → SVG 격자 도안(기호도) 변환을 위한
> 기호 정의 및 입력 문법 명세입니다.
> 코바늘 기호 체계는 [`symbol_system.md`](./symbol_system.md), 공통 아키텍처는
> [`architecture.md`](./architecture.md) 참조.

## 0. 코바늘과의 관계

- **탭 하나 = 크래프트 하나.** 한 도안 안에서 코바늘·대바늘을 섞지 않는다.
- **기호 코드는 공유하지 않는다.** 대바늘은 `k`, `p`, `yo`, `k2tog`, `ssk` 등
  **영문 대바늘 표준 약어를 그대로** 쓴다. 코바늘의 `X`/`V`/`A`/`O` 같은
  단일 문자 체계를 재사용하지 않는다 (같은 글자가 두 기법에서 다른 뜻이 되는 혼동 방지).
- **문법 골격만 공유**: `,` 구분, `(...)*N` 반복, 인라인 코멘트·색상.
  단, **반복수는 코 뒤에 붙인다** (`k3` = 겉뜨기 3코). 코바늘의 앞자리 표기(`3X`)와 반대.
- **구조는 공유**: 탭·저장·Dropbox 동기화·Read 모드 네비게이터는 그대로 재사용.

## 1. 기본 코 (Stitch)

대바늘 기호도는 **모눈(격자)** 위에 그린다. **1코 = 1칸**이 원칙이며,
칸 테두리를 항상 그린다 (코바늘과 달리 격자가 장식이 아니라 도안의 일부).

| 입력 | 별칭 | 한글 명칭 | 기호 | consume → produce |
|---|---|---|---|---|
| `k` | `K`, `knit` | 겉뜨기 | 세로선 `│` | 1 → 1 |
| `p` | `P`, `purl` | 안뜨기 | 가로선 `─` | 1 → 1 |
| `yo` | `YO` | 바늘비우기 | 원 `○` | 0 → 1 |
| `ktbl` | `k-tbl`, `tw`, `twk` | 꼬아 겉뜨기 | 꼬인 세로선 | 1 → 1 |
| `ptbl` | `p-tbl`, `twp` | 꼬아 안뜨기 | 꼬인 가로선 | 1 → 1 |
| `sl` | `slip`, `slwyif` | 걸러뜨기 | `V` | 1 → 1 |
| `ns` | | 코 없음 | 회색 채움 칸 | 0 → 0 |
| `co` | `caston`, `cast-on` | 코잡기 | 타원 | 0 → 1 |
| `bo` | `bindoff`, `bind-off` | 코막음 | 굵은 가로선 | 1 → 0 |

> `co40` 은 부모 단 없이 40코를 만든다 — 1단에 쓰면 코잡기 행이 격자 맨 아래에 그려지고,
> 2단부터 코 수 검증이 정확히 맞아떨어진다. `bo` 는 반대로 코를 없앤다.

> `ns`(no stitch)는 단마다 코 수가 다를 때 격자를 맞추기 위한 **표시 전용** 칸이다.
> 대부분 자동 삽입되므로 직접 입력할 일은 드물다 (§5).

## 2. 늘림 (Increase)

| 입력 | 별칭 | 한글 명칭 | consume → produce |
|---|---|---|---|
| `kfb` | `inc` | 한 코에 겉뜨기 2 (코늘리기) | 1 → 2 |
| `kfbf` | | 한 코에 겉뜨기 3 | 1 → 3 |
| `m1l` | `M1L` | 왼코 늘리기 | 0 → 1 |
| `m1r` | `M1R` | 오른코 늘리기 | 0 → 1 |
| `m1p` | `M1P` | 안뜨기 늘리기 | 0 → 1 |
| `yo` | | 바늘비우기 (구멍 남는 늘림) | 0 → 1 |

> `m1*` 계열은 코와 코 **사이**의 실을 끌어올리므로 부모 코를 소비하지 않는다 (consume 0).
> `kfb` 계열은 부모 코 하나를 소비해 여러 코를 만든다 (코바늘 `V`와 같은 구조).

## 3. 줄임 (Decrease) — 기울기가 핵심

대바늘 줄임은 **소비 코 수가 같아도 기우는 방향에 따라 기호가 다르다**.
따라서 코바늘 `A`(DEC) 하나로 묶지 않고 각각 별도 코로 등록한다.

| 입력 | 별칭 | 한글 명칭 | 기욺 | consume → produce |
|---|---|---|---|---|
| `k2tog` | `k2t` | 왼코겹치기 | 오른쪽 `╱` | 2 → 1 |
| `ssk` | `skpo`, `sl1-k1-psso` | 오른코겹치기 | 왼쪽 `╲` | 2 → 1 |
| `cdd` | `sk2p`, `s2kp` | 중심 3코 모아뜨기 | 중앙 `╱│╲` | 3 → 1 |
| `k3tog` | | 겉뜨기 3코 모아 | 오른쪽 | 3 → 1 |
| `sssk` | | 오른코 3코 모아 | 왼쪽 | 3 → 1 |
| `p2tog` | `p2t` | 안뜨기 왼코겹치기 | 오른쪽 | 2 → 1 |
| `ssp` | | 안뜨기 오른코겹치기 | 왼쪽 | 2 → 1 |
| `p3tog` | | 안뜨기 3코 모아 | 오른쪽 | 3 → 1 |

**등록된 별칭**: `k2tog`~`k5tog`, `p2tog`/`p3tog`, `ssk`/`sssk`, `ssp`, `cdd`(=`sk2p`/`s2kp`).
표에 없는 코 수는 `^N` 으로 지정한다 — 예: `k2tog^6` = 6코를 오른쪽으로 모아뜨기.

> 기욺 방향은 **겉면 기준**이다. 안면 단에서 뜬 `p2tog`는 겉면에서 `k2tog`와 같은
> 방향으로 기울어 보이며, 차트에도 그렇게 그려진다 (§6.2).

## 4. 교차뜨기 (Cable) — 여러 칸을 가로지르는 기호

케이블은 **한 기호가 N칸을 차지**한다. 코바늘에 없던 개념이라
`Op` 에 `span` 필드를 새로 둔다 (span = consume = produce).

### 표기

```
<앞코수>/<뒤코수><방향><베이스?>
```

| 입력 | 별칭 | 의미 | consume → produce |
|---|---|---|---|
| `2/2rc` | `2/2RC`, `c4b` | 2코 오른쪽 위 교차 | 4 → 4 |
| `2/2lc` | `2/2LC`, `c4f` | 2코 왼쪽 위 교차 | 4 → 4 |
| `1/1rc` | `c2b` | 1코 교차 (오른쪽 위) | 2 → 2 |
| `3/3lc` | `c6f` | 3코 교차 (왼쪽 위) | 6 → 6 |
| `1/2rc` | | 비대칭 교차 | 3 → 3 |
| `2/2rp` | `t4b` | 교차 후 뒤쪽 코를 안뜨기 | 4 → 4 |

- `<a>/<b>` + `r|l` + `c|p` 를 패턴으로 인식 (대소문자 무관). 표에 없는 조합도 자동 지원.
- 기호: span 칸 전체에 걸친 사선 다발. `r`은 왼쪽아래 → 오른쪽위 가닥이 **위**,
  `l`은 그 반대. 위에 오는 가닥은 끊김 없이, 아래 가닥은 끊어서 그린다.

## 5. 코 없음 (No Stitch) 자동 삽입

단마다 코 수가 다르면 격자가 어긋난다. 대바늘 차트 관행은
**빈 자리를 회색 칸(no stitch)으로 채우는 것**이다.

- 차트 폭 = 모든 단의 최대 코 수
- 각 단은 정렬 옵션(L / R / C)에 따라 배치, 남는 칸은 `ns` 로 채움
- 기본 정렬: **C(가운데)** — 래글런·삼각숄 등 대칭 증감이 대부분
- 사용자가 명시적으로 `ns` 를 넣으면 그 자리에 고정

## 5.1 열 맞춤 — 순 증감분만 조정

인접한 두 단은 **코 수가 달라진 만큼만** 조정한다. 핵심 규칙:

> 코 수가 변하지 않는 단은 격자를 **전혀 건드리지 않는다.**

그래서 레이스처럼 `yo`(늘림)와 `ssk`(줄임)가 상쇄되는 단은 빈 칸도, 넓힌 칸도 생기지 않고
직사각형 격자가 유지된다 (실제 차트 관행).

코 수가 변하는 단만 그 차이만큼 조정하며, 조정 위치는 **구조를 따른다**:

| 상황 | 위치 |
|---|---|
| 늘림 (`m1l`, `yo`, 단 중간 `co`) | 그 코 **바로 아래**에 빈 칸 |
| 줄임 (단 중간 `bo`, 소비되지 않은 코) | 그 코 **바로 위**에 빈 칸 |

`Cascade On/Off` 는 **조정 방식**만 바꾼다 (위치는 동일):

| | 늘림 `kfb` (1→2) | 줄임 `k2tog` (2→1) |
|---|---|---|
| **ON** | 아래 단 부모 칸이 **2칸 폭**으로 넓어짐 | 자식 칸이 2칸 폭으로 넓어짐 |
| **OFF** | 모든 칸 1칸 폭 + 부모 **옆에 빈 칸** | 모든 칸 1칸 폭 + 줄임 코 **옆에 빈 칸** |

## 5.2 되돌아뜨기 (Short row)

되돌아뜨기는 단 도중에 방향을 바꿔, 일부 코를 뜨지 않고 남긴다.
남긴 코를 **미작업 코(`unw`)로 명시**해서 단의 코 수를 보존하는 방식으로 표현한다.

| 입력 | 의미 | consume → produce |
|---|---|---|
| `wt` (`w&t`) | 되돌아뜨기 turn — 감아뜨기 | 1 → 1 |
| `ds` | 독일식 되돌아뜨기 (double stitch) | 1 → 1 |
| `unw` | 미작업 코 — 뜨지 않고 남긴 코 | 1 → 1 |

```
1: co20
2: k20
3: k12, wt, unw7      ← 가는 단: 12코 뜨고 turn, 남은 7코는 아직 안 지남 → 뒤에
4: unw7, p13          ← 오는 단: 그 7코는 이미 지나왔음 → 앞에
5: k20                ← 전체를 다시 주워 뜸
```

**`unw` 를 적는 위치**: 그 단의 **작업 순서**를 따른다.
아직 지나지 않은 코면 뒤에, 이미 지나온 코면 앞에 적는다.
올바르게 적었다면 가는 단과 오는 단의 회색 구간이 **같은 열**에 놓인다 — 차트가 바로 알려준다.

`unw` 는 `ns`(코 없음)와 다르다. `ns` 는 격자 정렬용 빈칸(0 → 0)이고,
`unw` 는 **실제로 바늘에 남아 있는 코**(1 → 1)라 다음 단이 이어서 뜰 수 있다.

## 5.3 단 중간 코막음 / 감아코

| 상황 | 표기 | 격자 표시 |
|---|---|---|
| 진동·목선 파기 (중간 코막음) | `k3, bo4, k3` | 코막음 칸 **위쪽**이 빈 칸으로 뚫림 |
| 감아코 (중간에 코 만들기) | `k3, co4, k3` | 새로 만든 칸 **아래쪽**이 빈 칸 |

둘 다 별도 문법 없이 기존 `bo`/`co` 를 단 중간에 쓰면 된다.
cascade 가 켜져 있으면 소비되지 않은 코 위, 부모 없는 코 아래로 빈 칸이 자동 전파된다.

## 5.4 배색 도안 (colorwork)

색은 코 단위로 지정하고(`k5:red`), 대바늘에서는 **칸 배경**으로 칠한다
(코바늘은 기호 선 색). 페어아일·인타르시아 모두 표현은 같다 —
실을 어떻게 다루는지는 도안 메모로 적는다.

- 기호는 배경 밝기에 따라 **자동으로 흰색/검정** 전환 (어두운 실 위에서도 보이도록)
- 차트 아래에 **범례** — 쓰인 색과 코 수 (실 소요량 가늠용). 색이 없으면 표시하지 않음
- 부동실(floats)·색 변경 지점은 차트에 그리지 않는다 (칸 색 자체가 표시)

```
3: k2:navy, (k2:cream, k2:navy)*5
```

## 6. 도형(shape)과 작성 방향 ★

대바늘 기호도의 대원칙: **차트는 항상 겉면(RS)에서 본 모습이다.**
입력은 **뜨는 대로**(as worked) 하고, 표시할 때 앱이 반전한다.

### 6.1 도형 축 — 코바늘과 다른 점

| 크래프트 | 도형 선택지 | 레이아웃 |
|---|---|---|
| 코바늘 | 원형 / 평면 | **도안 그림 자체가 바뀜** (방사형 좌표 ↔ 격자) |
| 대바늘 | **원통 / 평면** | **둘 다 같은 격자.** 바뀌는 것은 방향·반전 규칙뿐 |

즉 대바늘은 레이아웃 엔진이 하나(`grid.ts`)이고, shape 는 **각 단이 겉면인지 안면인지**를
결정하는 플래그로만 작용한다. UI 라벨도 "원형"이 아니라 **"원통"**이다.

| shape | 한글 | 단의 면 | 읽는 방향 | 기호 반전 |
|---|---|---|---|---|
| `round` | 원통뜨기 (윤편물) | **모든 단이 겉면** | 항상 우 → 좌 | 없음 |
| `flat` | 평면뜨기 (왕복) | 홀수단 겉면 / 짝수단 안면 | 홀수 우→좌, 짝수 좌→우 | **짝수단만** |

### 6.2 안면 단(WS) 반전 처리

평면뜨기 짝수 단은 입력된 Op 리스트에 두 가지 변환을 적용한 뒤 배치한다.

1. **순서 반전**: 뜬 순서(좌→우)를 차트 좌표(우→좌)로 뒤집는다.
2. **기호 반전**: 안면에서 뜬 동작을 겉면에서 본 모습으로 바꾼다.

| 뜬 것 (WS) | 차트 표시 (RS 기준) |
|---|---|
| `p` | `k` `│` |
| `k` | `p` `─` |
| `p2tog` | `k2tog` (오른쪽 기욺) |
| `ssp` | `ssk` (왼쪽 기욺) |
| `k2tog` (WS) | `ssp` 모양 |
| `ktbl` | `ptbl` |
| `m1l` / `m1r` | `m1r` / `m1l` |
| `yo`, `sl`, `ns` | 불변 |
| 케이블 `…rc` / `…lc` | 좌우 반전 |

- **토글 제공**: "뜨는 대로 표시" 를 켜면 반전을 끄고 입력 그대로 그린다
  (기존 종이 도안을 그대로 옮겨 적는 경우 대비).
- **단 번호 표기 위치**: 겉면 단은 격자 **오른쪽**, 안면 단은 **왼쪽**에 표기 (관행).
  방향을 번호 위치로 알 수 있으므로 코바늘의 ▶/◀ 마커는 쓰지 않는다.

### 6.3 `direction` 필드와의 관계

기존 `PatternRoundState.direction: 'forward' | 'reverse'` 를
대바늘에서는 **면(RS/WS)의 수동 오버라이드**로 재사용한다.
기본값은 shape + 단 번호로 자동 결정(`round` → 전부 RS, `flat` → 홀수 RS / 짝수 WS)하고,
짧은 단(short row) 등 예외에서만 사용자가 뒤집는다.

## 7. 격자 비율 (게이지)

실제 뜨개 코는 정사각형이 아니다 (가로가 넓고 세로가 짧음).

- 게이지는 **탭 단위 설정** — 편집기 헤더의 `게이지 [코] × [단] / 10cm`
- 셀 세로/가로 비율 = **코수 / 단수**. 예) 22코 30단 → 0.73 → 셀 20 × 14.7
- **가로는 20px 고정, 세로만 조정** — 게이지를 바꿔도 차트 가로 폭이 변하지 않는다
- 게이지 미입력·범위 밖(1~200)이면 기본 비율 **1 : 0.7**
- 미리보기 하단에 **실측 치수** 표시 — `가로 60코 ≈ 27.3cm · 세로 80단 ≈ 26.7cm`
  (늘림·줄임으로 단마다 코 수가 다르면 **가장 넓은 단** 기준)
- 저장 포맷에는 optional 필드로 들어가므로 버전 변경 없음 (구버전 파일 = 게이지 없음)

## 8. 입력 문법

### 8.1 반복수는 뒤에 (postfix)

```
k3          겉뜨기 3코
p2          안뜨기 2코
k2tog       (그 자체로 한 동작 — 숫자는 코 이름의 일부)
kfb2        코늘리기 2회
```

- 코바늘의 앞자리 표기(`3X`)와 반대. 대바늘 도안 관행을 따른다.
- 앞자리 표기(`3k`)도 파서가 받아주되, 정규화 시 `k3` 로 표시한다.
- `k2tog` 처럼 숫자를 포함한 코 이름은 longest-match 로 먼저 인식되므로
  `k2` + `tog` 로 쪼개지지 않는다.

### 8.2 단 입력 형식

```
1: k2, (p2, k2)*10
2: p2, (k2, p2)*10
3: k1, ssk, k36, k2tog, k1
```

- 단 번호 + `:` + 패턴 (코바늘과 동일)
- `to end` / `~` 축약은 **미지원** (v2 검토). 코 수를 명시하거나 `(...)*N` 사용.
- 도형(원통/평면)은 별도 필드.

## 9. MVP 범위 (Phase 1 — 구현 완료)

- **지원 기호**: `k` `p` `yo` `ktbl` `ptbl` `sl` `ns` /
  `kfb` `m1l` `m1r` `m1p` / `k2tog` `ssk` `cdd` `k3tog` `sssk` `p2tog` `ssp`
- **지원 도형**: `flat`(평면), `round`(원통) — **둘 다 같은 격자 레이아웃**
- **지원 그룹**: `()` 반복 `*N`
- **자동 처리**: no-stitch 채움, WS 반전, 단 번호 좌우 배치
- **미지원(추후)**: 케이블(§4, Phase 2), 배색(fair isle) 칸 채우기, 짧은 단(short row),
  코막음/코잡기(`bo`/`co`), 게이지 기반 실측 치수
