# 패턴라이터 v2.0 기능 조사 (외부 도구 비교)

> 사용자가 구입한 코바늘 도안 작성 프로그램 **패턴라이터(뭉치공방) v2.0** 의 사용설명서(71쪽)를
> 읽고 정리한 문서. 우리 서비스의 대규모 리뉴얼에서 **무엇을 만들지 고르기 위한 참고 자료**다.
>
> ⚠️ **저작권** — 설명서 3~4쪽에 프로그램 코드·기호 그래픽·화면 디자인의 복제 금지가 명시되어 있다.
> 이 문서는 기능 구조와 입력 문법 **아이디어**를 참고하기 위한 것이며, 기호 SVG·화면 구성·코드를
> 가져오지 않는다. 기호는 우리 체계(`symbol_system.md`, `knit_symbol_system.md`)로 직접 그린다.
> 같은 뜨개 용어(`같은코`, `코너`, `테두리` 등)는 업계 공통 용어라 사용에 제약이 없다고 본다.

## 0. 한눈에 보기

- **코바늘 전용** 웹 도구. 크롬만 지원, 휴대폰 미지원. 기호 130여 개.
- 구조는 우리와 거의 같다 — 왼쪽 입력창 / 가운데 캔버스 / 오른쪽 기호 목록,
  브라우저(localStorage) 저장 + `.json` 파일 백업, PNG·JPG·PDF 내보내기, 서버 저장 없음.
- **한글 기호 이름**을 뜨는 순서대로 적는다 (`짧은뜨기 2코 늘려뜨기 * 6`).
  우리는 약어 토큰(`X`, `V`, `sc`) 기반 — 둘 다 "글로 적으면 그려진다"는 같은 발상.
- 설계 태도의 핵심 차이: **"모든 도안을 자동으로 정확히 그릴 수는 없다"** 고 설명서에 못 박고,
  예외는 **손으로 옮겨 다듬고 그 배치를 파일에 저장**하게 열어 둔다 (7장).

## 1. 입력 문법

| 적는 법 | 뜻 |
|---|---|
| `짧은뜨기 6` | 한 줄 = 한 단. 기호 이름 + 코 수 |
| `기둥코 1, 짧은뜨기 5, …` | 쉼표로 나열 |
| `… * 6` (`×`, `x`, `6회` 동일) | 반복 |
| `(짧은뜨기, 짧은뜨기 2코 늘려뜨기) * 6` | 묶음 반복 |
| `11~25단: 짧은뜨기 30` | 증감 없는 단 **중략** — 사이 단은 그리지 않고 `~` 로 접어 표시 |
| `1~2단 반복*3` | 앞의 여러 단을 통째로 되풀이 (접지 않고 모두 그려짐) |
| `[16단] 짧은뜨기 48` | 16단 코에 새 실을 걸어 뜨기. 번호가 **이어져** 첫 줄이 17단 |
| `머리연결부분 [16단]` | 같은 걸어 뜨기지만 **새 파트로 1단부터** 다시 셈. 이름이 라벨에 붙음 |

- 단 번호는 적지 않으면 줄 순서대로 자동. `1단:` 처럼 직접 적어도 된다.
- 걸어 뜬 자리는 도안 왼쪽에 **파란 점선 + 세로 문구**("16단 이랑에 새 실")로 자동 표시되고,
  선택해서 색·문구를 바꾸거나 지울 수 있다. 평면으로 펼쳐진 단에서만 표시된다.

### 코 수 세는 규칙 (2장)

- `기둥코 1` → 코로 세지 **않음**. `기둥코 2~5` → **1코**로 셈.
- `기둥코 3(추가)` → 기초 사슬을 차지하지 않고 따로 그려지며 1코로 셈.
- 단 **끝**의 빼뜨기는 코 수 제외, 단 **중간**의 빼뜨기는 포함.
- 맨 앞의 `빼뜨기 2` 는 코를 만들지 않고 **단 시작 자리만** 옮긴다 (영문 `slst in next 2 st, ch 3`).
- `사이사슬코` 는 코 수에서 빠지고, `연결사슬코` 는 들어간다 (아래 코를 그만큼 스킵).
- 라벨은 `3(18)` 형태 — 단 번호 + 그 단의 코 수. 그래니 모드는 라벨을 붙이지 않는다.

## 2. 모드 (= 우리의 shape)

| 모드 | 첫 줄 | 비고 |
|---|---|---|
| 원형 | `짧은뜨기 6` / `사슬코 6` / `반원` | 매직링 · 사슬 고리 · 반원(단마다 방향 반전) |
| 왕복 | `사슬코 20` | `시작 방향 (왼→오 / 오→왼)` 토글 |
| 타원 | `사슬코 7` / `지퍼 20` | 기초 사슬 양쪽을 돌아간다. 지퍼 그림 위에 코를 얹는 모드도 있음 |
| 비정형 | `짧은뜨기 6` | 4·5·6·8각으로 도는 도안 (코너 늘림) |
| 그래니 | `원형코` / `사슬코 8` | `코너(…)` 가 나오는 단부터 사각으로 그려짐 |
| 배색 도안 | — | 픽셀 격자 에디터 (별도 도구) |
| 방안뜨기 | — | 칸 채우기/비우기 → 기호 도안 (별도 도구) |

**`N단 이후 평면`** (원형·타원): N단까지는 링으로, 그 뒤부터는 평면으로 쌓아 그린다.
`0단 이후 평면` 이면 원통을 세로로 갈라 펼친 그림이 되고(왕복과 달리 모든 단이 한 방향),
`사슬 N번째 코부터 펼침` 으로 가른 자리를 옮겨 무늬를 대칭으로 배치할 수 있다.
걸어뜨기가 있는 원통 도안은 `N단 이후 평면`을 0으로 둬야 선이 정상으로 그려진다고 안내한다.

## 3. 무늬 표기

| 표기 | 뜻 |
|---|---|
| `같은코(한길긴뜨기 3코, 사이사슬코 2, 한길긴뜨기 3코)` | 한 코에 여러 코 — 발이 모이고 머리가 벌어짐 (조개·부채무늬) |
| `한길긴뜨기 3코 코아래` | 아래 단 사슬을 통째로 감싸 뜨기 |
| `2코 스킵` | 건너뛰기. **코 앞**이면 건너뛰고 뜨고, **코 뒤**면 뜨고 나서 건너뛴다 |
| `사이사슬코` / `연결사슬코` | 코 사이 아치. 후자는 아래 코를 스킵하며 코 수에 포함 |
| `피코빼뜨기 5` | 가장자리 장식. 진행 방향에 따라 빼뜨기 붙는 쪽이 자동 반전 |
| `코너(사이사슬코 2)` | 그래니 꼭짓점. 코너 사이 기호는 변에 고르게 분배 |
| `이랑 위(짧은뜨기 12)` / `이랑 아래(…)` | 괄호로 묶은 기호 위/아래에 이랑 선 |
| `한길긴뜨기 앞걸어뜨기` | 아래 코의 **기둥**에 걸어 뜨기 (골지·꽈배기) |
| `… 앞걸어뜨기 1단 2번째 코` | 걸 코를 직접 지정 |
| `… 앞걸어뜨기 이어서` | 가장 가까운 아래 단의 걸어뜨기에 자동으로 이어 걸기 |
| `한길긴뜨기 2코 오른코 위 교차뜨기` | 교차뜨기 / `앞걸어 … 교차뜨기` 는 걸어 교차 |
| `^( … )`, `<`, `가로( … )` | **돌기** — 한 코에서 위로 뻗었다가 사슬에 걸며 되돌아오는 예외 구조 |
| `…(시작코)` | 줄임코가 단 첫 코일 때, 기둥코가 함께 그려진 모양. 평면에서 좌우 자동 반전 |

## 4. 조각 · 옷

- **조각**: `발 A` 처럼 이름만 적은 줄부터 새 조각 (단 번호 1단부터 다시). 이름 10자 이내.
- **잇기**: `잇기 사슬코 4` → 조각들을 사슬로 이어 몸통으로. 사슬 없이 붙이려면 `잇기`.
  같은 조각이 둘이면 한 번만 적어도 한 벌 더 뜬 것으로 본다. 몸통 코 수 = 양쪽 코 + 사슬×2.
- **나누기**: `나누기 2` → 나뉘는 부분 사이에 뜨지 않고 남길 코 수. 안 맞으면 경고.
- **파트**(왕복, 옷): `파트 2` = 새 실로 시작하는 파트 개수. 실을 안 끊고 올라가는 쪽은 그냥 이어 적는다.
  **진동 코 수는 자동 분배** (나누기 직전 단 코 수 − 각 파트 코 수 → 남은 코를 겨드랑이에 균등 배분).
  `오른쪽 목 (8코부터)` 로 새 실 거는 자리를 지정. 단춧구멍처럼 갈라졌다 다시 합치는 구조도 지원.
- **테두리**: 가장자리 코 수·단 수를 세지 않고 **한 코(한 단)에 뜰 규칙**만 적는다.
  `테두리 아래: 짧은뜨기` / `테두리 왼쪽: 1단마다 사슬코 2, 빼뜨기` /
  `테두리 등판 위: 3코마다 한길긴뜨기 4코 늘려뜨기` / 모서리는 `테두리 왼쪽 아래: …`.
  조각 이름을 붙여 `테두리 등판 오른쪽: …` 처럼 변을 지정한다.
- `실 끊기(▼)` · `실 연결(▽)` 기호를 캔버스에 직접 삽입.

## 5. 다듬기 · 꾸미기 · 내보내기

- **수동 보정**: 클릭/드래그 선택, 박스 선택, Shift 추가 선택, 크기 조절·회전 핸들, 정렬 스냅,
  ⌘Z / ⌘⇧Z, **수동 이동 초기화**(지금까지 손으로 옮긴 개수를 메뉴에 숫자로 표시), **배치 새로 계산**.
- **배치 고정**: 저장할 때 **코의 자리까지 함께 저장**해, 프로그램이 업데이트돼도 도안 모양이 유지된다.
  새 배치 규칙을 적용하려면 `편집 → 배치 새로 계산` 을 눌러야 한다.
- 색: 단별 기호색 / 단 배경색, 선택한 코만 칠하기, **걸어뜨기·테두리만 일괄 색칠**, 전체 초기화.
- 라벨: 단 라벨 `3`, 단(코수) 라벨 `3(18)`, **바깥 코수표**(단·코수·증감 — 증감 없는 단은 대각선),
  방향 화살표. 라벨·표는 드래그 이동 + 크기 조절, 글꼴/굵기/크기 설정, 라벨·기호 크기 % 일괄 조절.
- **따라읽기**: 현재 뜨는 단만 또렷하게, 나머지는 흐리게. 접힌 `11~25단` 은 몇 번째 반복인지 세어 준다.
- 삽입: 텍스트 · 사진 · 도형(원/화살표/별/하트/…) · **레퍼런스 이미지**(도안에는 안 나옴) ·
  **자동 기호 범례** · 워터마크.
- 기호 목록 버튼 두 개: *클릭 → 이름 복사* / *클릭 → 캔버스 삽입*(글로 적기 어려운 코를 손으로 꽂기).
- 내보내기: 용지(A4 등)·방향을 **처음에** 정하고 시작하도록 권장. PNG / JPG / PDF /
  **여러 도안 PDF 병합**(저장된 도안을 골라 순서 정해 한 파일로).
- 11장은 전부 문제 해결("도안이 안 그려져요", "코 수가 달라요", "걸어뜨기 선이 안 이어져요" …),
  부록은 출력해서 붙여 두는 **문법 치트시트**.

## 6. 우리 서비스와의 대조

### 우리가 이미 가진 것 (또는 더 나은 것)
- 대바늘 지원 (상대는 코바늘 전용) — 격자 도안, 겉/안면 반전, 되돌아뜨기, 교차뜨기.
- 여러 도안 탭 + 워크스페이스, 도안 복제, Dropbox 동기화, 3D 미리보기, 서술 도안,
  게이지, 읽기 모드, 메모(도안·단), 마커, 색 모드, 빈칸 없음/열 맞춤 같은 레이아웃 옵션.
- 코 수 검증을 **단마다 초과/부족으로 명시** (상대는 라벨 숫자로 사용자가 눈으로 확인).

### 없는 것 — 리뉴얼 후보
우선순위는 "도안을 못 그리게 막는 것 > 반복 노동 > 꾸미기" 순으로 매겼다.

| 순위 | 기능 | 왜 |
|---|---|---|
| A | **단 중략 `11~25단:`** / **앞 단 반복 `1~2단 반복*3`** | 긴 도안에서 줄 수가 선형으로 늘어나는 걸 막는다. 읽기 모드·내보내기에도 직결 |
| A | **걸어뜨기(앞·뒤걸어)** + 걸 코 지정 + `이어서` | 골지·꽈배기 코바늘 도안을 아예 못 적는다. `CrochetStitchKind` 에 종류가 없음 |
| A | **수동 보정 + 배치 저장** | 자동 레이아웃의 탈출구. cascade/빈칸 규칙을 무한히 늘리는 대신 손으로 고치게 한다 |
| B | **테두리** | 옷·담요 도안의 필수. "한 코(한 단)에 뜰 규칙" 모델이 간결하다 |
| B | **조각 · 잇기 · 나누기** | 인형 도안. 단 번호 재시작 + 코 수 자동 합산 |
| B | **`N단 이후 평면` · 펼치는 자리** | 우리는 탭 단위 `circular`/`flat` 뿐 — 원통 도안을 평면으로 보여줄 수 없다 |
| B | **같은코 머리 벌어짐 · 코아래 · 사이/연결 사슬 구분** | 조개·부채·그물무늬. 우리 `[...]` 는 있지만 사슬 종류 구분이 없다 |
| C | **파트 + 진동 자동 분배** | 옷 도안. 구현 난도가 가장 높다 |
| C | **타원 · 비정형(다각형) · 반원 · 그래니 모드** | 모드가 늘면 레이아웃 엔진이 모드마다 갈라진다. 수요 확인 후 |
| C | **바깥 코수표(증감 포함) · 방향 화살표 · 자동 기호 범례 · 워터마크** | 내보내는 도안의 완성도 |
| C | **용지 설정(A4) · PDF 내보내기 · PDF 병합** | 지금은 SVG/PNG 뿐 |
| C | **배색 도안 · 방안뜨기 · 글씨→격자** | 성격이 다른 별도 도구 |
| C | 기호 목록에서 **캔버스에 직접 삽입** | 수동 보정과 묶어서 |

### 설계 메모
- `기둥코 1` 은 코로 세지 않고 `기둥코 2~5` 는 1코로 세는 규칙은 우리 `tc(...)` 와 다르다 —
  리뉴얼 때 코 수 세는 규칙을 문서로 한 번 정리하는 게 좋다.
- 상대는 **경고로 알려주고 그대로 그린다**(기둥코 추가 등). 우리는 검증 오류로 막는 쪽 —
  어디까지 막고 어디부터 "적은 대로 그리기"로 둘지 기준이 필요하다.
- 단 번호를 **조각/파트마다 다시 세는** 모델은 우리 `PatternRoundState` 에 없는 개념이다.
  되돌아뜨기 "이어짐"(한 단이 안 끝난 상태)과 함께 **단 번호를 계산하는 한 곳**을 만들어 두면 좋다.

## 7. 구현 여부 점검 (2026-10-07)

### 7.2 되기는 하지만 **셈법이 다른 것**

| 항목 | 설명서 | 우리 | 영향 |
|---|---|---|---|
| 단 끝 빼뜨기 | 코 수에서 뺀다 | **1 → 1 코로 센다** (`10O, sl` = 11코) | 원형 도안을 설명서처럼 적으면 코 수가 1 어긋난다 |
| 기둥코 1 | 코로 안 센다 | **1코로 센다** (기둥코 2~5 와 같게) | `tc(O), 16X` 가 17코를 쓴다 → 초과 경고 |
| `사이사슬 2, 2코 스킵` | 아래 단 코를 건너뜀 | 단 안에서 만든 **사슬을 먼저 건너뛴다** | 그물·아치 무늬에서 코 수 부족 경고 |

→ 셋 다 "코 수를 어떻게 세는가"의 문제다. 리뉴얼 때 **코 수 세는 규칙**을 한 번에
정리하면서 맞추는 게 좋다 (설명서 11-2 의 표와 같은 기준표를 우리도 둘 것).
